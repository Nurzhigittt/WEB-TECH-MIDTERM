# FRAME Movie Website

Topic: Movie Website — information, ratings, trailers and reviews.

FRAME is a movie website for our Web Technologies midterm project. It includes Interstellar, Inception and Dune. There are five pages: Home, Movies, Ratings, Trailers and Reviews.

The website has movie posters and descriptions, a ratings table, links to official trailers and sample reviews. A navigation menu connects all pages. The layout adapts to computers, tablets and phones. Ratings are examples, and the review form does not send or save data.

Technologies: HTML, CSS and Bootstrap 5.3.3. Flexbox, Grid and media queries are used for the layout. The Roboto font is connected through Google Fonts.
